# Provenance and reuse

Record bibliographic metadata first. Verify reuse permission for the specific table, figure or dataset before storing extracted data. Keep licence terms, extraction method, uncertainty and experimental conditions with the original observation. Cite the original source for every derived parameter and retain intermediate conversions. Do not overwrite historical evidence; issue a new revision and explicitly select it for new experiments. Educational assumptions must remain distinguishable from direct measurements. No third-party scientific dataset ships in Phase 1.
