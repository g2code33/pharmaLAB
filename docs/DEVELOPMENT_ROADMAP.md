# Development roadmap

1. Exercise native builds and offline installation on clean Windows and Ubuntu systems. Expand accessibility, recovery and concurrent-write testing.
2. Curate licensed, context-specific evidence for guinea pig ileum. Review extraction independently and record uncertainty.
3. Approve a parameter revision and protocol, implement the independent engine, and calibrate against designated data.
4. Independently validate against held-out measurements before enabling biological recording, quantitative analysis or claims of accuracy.
5. Add other preparations through separate model specifications. Consider optional 3D only after validating 2D usability and performance on integrated graphics.
