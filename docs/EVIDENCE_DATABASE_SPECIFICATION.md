# Evidence register

`src/evidence/register.ts` defines the evidence record. Identify each dataset by immutable revision ID; preserve parameter, species, tissue, drug, method and preparation conditions. Preserve original numerical value and units separately from future derived conversions. Sample size may be unknown; record uncertainty without guessing.

Publication title, authors, year, stable link, extraction method, licence, calibration status, validation status and notes travel with the record. Classify it as directly measured, estimated from experimental data, extracted from published figures or an educational assumption. A passing structural check is neither a reuse licence nor independent validation. The Analysis register intentionally starts empty. Research intake, revision approval and numerical calibration are later work.
