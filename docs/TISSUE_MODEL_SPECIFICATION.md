# Tissue models

First target: isolated longitudinal guinea pig ileum with isometric tension recording. Foundation version identifies the notebook contract only. Rabbit jejunum, chick biventer cervicis and rat artery are planned. `TissuePreparation` describes family, method, conditions, evidence and version. A common renderer does not imply a common response equation. In particular, chick biventer needs skeletal neuromuscular dynamics rather than intestinal smooth muscle. Each preparation needs separate evidence and acceptance criteria.
