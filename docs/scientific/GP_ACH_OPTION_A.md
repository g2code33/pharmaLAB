## Running the experiment

1. In **Laboratory → New experiment**, keep **Protocol simulation** (or choose the original bath-only recorder to work without a tissue model). The default protocol uses the Corbett & Lees MPLM context. The authors describe small intestine excluding the terminal 10–12 cm, not a precisely localised distal ileal segment. Do not silently assume their sampled region matches other ileum studies.
2. Select a preparation before starting. MPLM uses the published isometric midpoint. Intact segment uses Aboulafia's observed secondary onset; its potency is an assumption. Longitudinal strip and mucosa-deprived segment are **entirely exploratory isometric scenarios**: their isotonic Suzuki potency records remain in Evidence replay. Selecting a profile changes the displayed conditions, source, default dose and registry. No antagonists or other agonists.
3. Select single, prolonged, cumulative, ascending non-cumulative, repeated equal doses, conditioning/retest, or manual. In manual mode **Add ACh now**, advance, wash, advance and redose. Scheduled doses use `Vadd = Vbath(Ctarget − Cbath)/(Cstock − Ctarget)` with assumed stock 100× the selected final concentration. Full exchange restores the initial volume. Choose duration before starting; a short duration truncates the protocol rather than accelerating the tissue. Start/pause/resume/stop, select playback speed, inspect samples, or interrupt a scheduled sequence with Wash now.
4. Units are deliberately distinct: nominal ACh in M, active components in dimensionless scenario units, display in % of scenario scale (may exceed 100%). **Not percent of a measured maximum.** Optional gram output adds the chosen passive load to a hypothetical active scale; this does not measure baseline tone. The transducer and plot read the same sample. Isometric mounting does not imply shortening; the SVG is not an input to the engine. No new 3D renderer.
5. Select an inspection second or window to pan/zoom. Overlay a saved run only with matched preparation and display scale/load. The table of exposure measurements defines all windows. `Export trace CSV` exports only acquired samples; `curve CSV` is the static drive, not peak force observed at each dose. The first CSV row contains quoted JSON metadata. Registry JSON contains context, provenance and assumptions. Experiment JSON includes the replay envelope and simulated samples. **Save experiment** before leaving to persist in IndexedDB or the existing desktop SQLite store. Analysis → Review regenerates the saved trace; Experiments → Import backup accepts either a backup array or the exported experiment envelope. Duplicate IDs are not overwritten. Older runs keep their original reader.

## What the software models

`src/simulation/ach/protocols.ts` holds source contexts, units, editable bounds and provenance. `protocol.ts` executes an integer-second causal simulation: an addition or full exchange at second *s* changes the bath immediately, while its mechanical effect first appears in later samples. No hydrolysis rate is known, so the assumed tissue concentration equals the mixed nominal concentration. `TissueStep` is the boundary for a future alternative; the current state has no intracellular concentrations.

The static drive is a stable log-scale Hill fraction, not a fit of the full concentration–peak-force relationship. An increment in drive excites a decaying pulse proportional to `x exp(1−x)` where `x` is time/peak time. The sustained component approaches a drive-dependent fraction; a second, delayed pulse represents prolonged contact. While exposed, a bounded history index approaches drive; off drug it decays separately from faster mechanical relaxation. Conditioning attenuates the next phasic pulse and can enhance and advance the tonic response. These shapes, their numerical time scales and multipliers are **model choices**, not molecular rate constants. The secondary-onset default for the intact reference is the reported mean converted to seconds, not a calibrated onset law. Corbett & Lees describe a spike generally peaking in <20 s and a later plateau usually within 2 min across agonists: descriptive checks, not estimates of an ACh time constant. No spontaneous tone, enzyme activity, Ca transport, temperature extrapolation, or stochastic animal variability is claimed.

`comparison.ts` accepts bounded, local `ach-replicates/1` inputs only for the chosen source context. Export the blank template; each independent preparation needs `preparationId`, `baselineG`, repeated absolute `plateauG` observations, and `points: [{molar,g}, …]`. Include dataset identity, experimental conditions, citation and rights. The context ID is a declaration by the importer, not an automated methods audit. `estimateCurve` fits logit of baseline-corrected fractional force vs ln(M) per preparation, using the 20–80% region bracketing the midpoint. Plateau increment is obtained independently; export includes residuals for **all** points, RMSE, constraints and distribution-free median intervals when sample size permits. Local fitted results never silently rewrite the registry. No experimental points were generated to exercise the fit; tests use mathematical fixtures only. No matched independent holdout has been obtained.
